# Vanilla HyprArch wallpapers

SPDX-License-Identifier: GPL-2.0-only

Official Wallpaper Set v2 comprises the eight 3840×2160 RGB `Wolkenstein`
Light and Dark PNG images in this directory. They are original Vanilla
HyprArch project assets provided by the project author and are released under
GPL-2.0-only, using the repository's root `LICENSE` text. This set replaces the
previous starter artwork for fresh installations without changing the managed
filenames.

The matching `Wolkenstein_1_light.png` and `Wolkenstein_1_dark.png` files are
the deterministic default pair. The other numbered pairs are bundled choices
for user selection.
