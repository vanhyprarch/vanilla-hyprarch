# Vanilla HyprArch wallpapers

SPDX-License-Identifier: GPL-2.0-only

The eight `Wolkenstein` Light and Dark images in this directory are original
Vanilla HyprArch project assets provided by the project author. They are
released under GPL-2.0-only, using the repository's root `LICENSE` text.

The matching `Wolkenstein_1_light.png` and `Wolkenstein_1_dark.png` files are
the deterministic default pair. The other numbered pairs are bundled choices
for user selection.
