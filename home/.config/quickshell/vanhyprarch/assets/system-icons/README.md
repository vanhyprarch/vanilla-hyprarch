# Dock system icons

These 19 SVGs are unmodified, permanently vendored static assets from
[Lucide](https://github.com/lucide-icons/lucide), commit
`d672fc43dbf60962d9d829e35bc3b3e5ed89a178` (`icons/<filename>.svg`).
The revision records provenance and attribution only. There is no Lucide package,
runtime download, generated asset, synchronization or update mechanism. Future
Lucide releases require no action. `SHA256SUMS` records the original bytes.

The adjacent unmodified upstream `LICENSE` contains the Lucide ISC license and
required Feather/MIT attribution (including the selected `info` and `moon`).
These notices travel with the assets in the existing managed Quickshell tree
and release archive. They do not change the license of other Vanilla code.

The existing `SystemIcon.qml` uses these local files at the existing logical
size and tints their alpha mask with `theme.accent`. Their original 24-unit
geometry, round joins/caps and stroke width 2 are unchanged in Light and Dark.
